# Requisitos do ManutenAi

## 1. Descrição do sistema

O *ManutenAi* será um sistema destinado ao registro e acompanhamento de problemas de manutenção encontrados no ambiente escolar.

## 2. Requisitos funcionais

### RF01 — Registrar problema

O sistema deve permitir que o usuário registre um problema de manutenção encontrado na escola.

### RF02 — Informar dados do problema

O sistema deve permitir informar:

- Descrição do problema;
- Local onde o problema foi encontrado;
- Tipo do problema.

### RF03 — Visualizar problemas

O sistema deve permitir visualizar os problemas de manutenção registrados.

### RF04 — Consultar status

O sistema deve permitir visualizar a situação de cada problema registrado.

Os status poderão ser:

- *Pendente*
- *Resolvido*

### RF05 — Marcar problema como resolvido

O sistema deve permitir alterar o status de um problema para *Resolvido* após a manutenção ser realizada.

## 3. Requisitos não funcionais

### RNF01 — Facilidade de uso

O sistema deve possuir uma interface simples e fácil de utilizar.

### RNF02 — Organização

As informações dos problemas devem ser apresentadas de maneira clara e organizada.

### RNF03 — Clareza

O sistema deve apresentar de forma clara as informações relacionadas ao problema, como local, descrição e status.

## 4. Escopo

O projeto contempla:

- Registro de problemas;
- Informações sobre os problemas;
- Visualização dos problemas;
- Acompanhamento do status;
- Marcação de problemas como resolvidos.

### Fora do escopo

Não fazem parte desta primeira versão:

- Login;
- Chat;
- Notificações;
- Sistema financeiro;
- Calendário;
- Mapa da escola;
- Cadastro de funcionários.
