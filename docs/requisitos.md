Requisitos do OrganizaAí

1. Descrição do sistema

O OrganizaAí será um sistema simples para ajudar estudantes a organizar suas atividades escolares e acompanhar seus prazos de entrega.

2. Requisitos funcionais

RF01 — Cadastrar atividade

O sistema deve permitir que o estudante cadastre uma atividade escolar.

RF02 — Informar dados da atividade

O sistema deve permitir informar o nome da atividade, a matéria e a data de entrega.

RF03 — Visualizar atividades

O sistema deve permitir que o estudante visualize as atividades cadastradas.

RF04 — Organizar por data

O sistema deve apresentar as atividades organizadas de acordo com a data de entrega.

RF05 — Marcar atividade como concluída

O sistema deve permitir que o estudante marque uma atividade como concluída.

3. Requisitos não funcionais

RNF01 — Facilidade de uso

O sistema deve possuir uma interface simples e fácil de utilizar.

RNF02 — Organização

As informações das atividades devem ser apresentadas de forma clara e organizada.

RNF03 — Acessibilidade

O sistema deve buscar uma apresentação que facilite a visualização e utilização por diferentes estudantes.

4. Escopo

O projeto contempla o cadastro, a visualização, a organização por data e a conclusão de atividades escolares.

Não fazem parte desta versão funcionalidades como login, sistema de notas, mensagens, notificações, calendário, aulas online ou comunicação com professores.
