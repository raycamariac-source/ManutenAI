Requisitos do ManutenAi

1. Descrição do sistema

O ManutenAi será um sistema para registrar e acompanhar problemas de manutenção encontrados no ambiente escolar.

2. Requisitos funcionais

RF01 — Registrar problema

O sistema deve permitir o registro de um problema de manutenção.

RF02 — Informar dados do problema

O sistema deve permitir informar a descrição, o local e o tipo do problema.

RF03 — Visualizar problemas

O sistema deve permitir visualizar os problemas de manutenção registrados.

RF04 — Visualizar status

O sistema deve permitir visualizar o status de cada problema registrado.

RF05 — Marcar problema como resolvido

O sistema deve permitir alterar o status de um problema para resolvido após sua solução.

3. Requisitos não funcionais

RNF01 — Facilidade de uso

O sistema deve possuir uma interface simples e fácil de utilizar.

RNF02 — Organização

As informações dos problemas devem ser apresentadas de forma clara e organizada.

RNF03 — Clareza das informações

O sistema deve apresentar de forma clara a descrição, o local e o status de cada problema.

4. Escopo

O projeto contempla o registro, a visualização e o acompanhamento de problemas de manutenção escolar.

Não fazem parte desta versão funcionalidades como login, chat, notificações, sistema financeiro, calendário, cadastro de funcionários ou mapa da escola.
